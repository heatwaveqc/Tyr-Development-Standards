# Tyr Development Standards

Canonical shared engineering governance for heatwaveqc projects. Adopt an immutable commit of this repository using the bootstrap in `templates/AGENTS.md`. Read the core and only the task-specific procedures it routes to. Local project contracts retain their own design, branch topology, build and release gates. No consumer is migrated automatically.

Initial standards derived from Too Much Magic's November 2026 governance; see provenance in CHANGELOG.md.
