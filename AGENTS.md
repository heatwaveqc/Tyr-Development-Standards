- Owner controls new design, scope, destructive actions and release authorization. Execute settled requirements within delegated authority.

- Separate source readiness, integration, runtime acceptance and release. Report actual evidence, not inferred success.
- Maintain canonical work ledger and finish lifecycle. Local contracts define concrete authority and stricter gates. Resolve conflicts before affected mutations.
