# QA
Distinguish static checks, scoped compilation/unit tests, integration preflight, assembly, runtime smoke, packaged artifact, client launch and behavioral acceptance where applicable. Report exact revision, actual commands/checks/results and omitted checks. Preserve evidence for unchanged behavior; never invent results. Routine quick CI may run under local policy; expensive builds, deployments, publication and destructive tests require local authorization (ask owner if absent). Source-ready can merge under delegated review with runtime obligations recorded. Do not skip required CI. Dispatch/receipt is not success. Verify actual branch protections rather than treating documentation as enforcement.
